## 帖子 2：你的 AI 編碼助手可能被駭了

資安公司 Tenet Security 發現一個叫「Agentjacking」的攻擊手法。

駭客發一個假的 Sentry 錯誤報告，Claude Code、Cursor、Codex 這些 AI 編碼代理就傻傻的把惡意程式碼跑下去。

不是漏洞，是設計上的信任問題——AI 看到錯誤報告就急著幫你修，結果修出更大的洞。

用 AI 寫 code 的朋友注意了，不是跑得動就沒事。

#AISecurity #ClaudeCode #Agentjacking

## 帖子 3：檔案系統是 AI Agent 的新玩法

開發者圈最近在討論一個有趣的趨勢：

與其讓 AI Agent 通通用 API 溝通，不如讓它們讀寫檔案。

為什麼？因為檔案系統本身就是成熟的狀態管理工具——權限、鎖定、版本控制、備份，什麼都有。

Agent A 寫一份報告到 /tasks/，Agent B 讀完繼續做，比在那邊搞 MCP 協議簡單多了。

有時候最老的技術就是最好的答案。
